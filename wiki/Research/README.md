## Research Template

When creating a new research page, use this structure:

```
# Research: <Topic>

**Issue**: #<n>
**Status**: In Progress | Completed | Deferred
**Author**: @<handle>
**Date**: YYYY-MM-DD

## Question
What are we trying to answer?

## Context
Why do we need this? What decision does it unblock?

## Options Evaluated

### Option A: <Name>
...

### Option B: <Name>
...

## Comparison

| Criterion | Option A | Option B |
|---|---|---|
| | | |

## Recommendation
...

## Decision
_(filled in once a decision is made — link to ADR if applicable)_
```
